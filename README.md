# jusenho-game

Mini games from Carson for dorm Jusenho. Live: https://keeonho.github.io/jusenho-game/

- **catch!**: move the basket and catch photocards of Juhoon, Seonghyeon and Keonho
- **memory match**: find every pair
- **our album**: a scrapbook whose pages flip as you scroll, ending with a letter

Built with GSAP ScrollTrigger, Lenis and three.js (holographic photocards), all from CDN, in one `index.html`.
`reel/` is the Remotion source for the stop-motion clips (`npx remotion render JusenhoReel`).

Member photos: Wikimedia Commons (CORTIS category) and public fan/press profile pages.
